# HIGHST · Vietnam Urology Webinar

영어 발표 초안과 수술주기별 촬영 계획을 함께 보는 웹페이지입니다.

[발표·촬영 계획 열기](https://notoow.github.io/vietnam-urology-webinar/)

## 영상팀 사용 방법

수술팀 전용 링크를 열면 회원가입이나 로그인 없이 공동 촬영 목록을 사용합니다.

1. 왼쪽 **수술주기 기록**을 엽니다.
2. 수술 전·중·후에서 과정을 고르고 **촬영할 장면**만 적습니다.
3. 필요한 과정은 추가하고, 이름을 바꾸거나 삭제합니다. 촬영 후 완료 표시를 누릅니다.
4. **팀 링크 복사**로 같은 목록을 공유합니다.

저장한 변경은 다른 팀원의 화면에 실시간 반영됩니다. 같은 과정을 동시에 수정하면 먼저 저장된 내용을 보호하고, 나중 저장에는 비교 안내를 표시합니다. 문장 단위 동시 타이핑 편집기는 아닙니다.

담당자·소요시간·관리·준비물·대응·기록 필드는 비활성화했습니다. 기존 데이터가 있으면 보존합니다. 초기 목록은 수술팀과 정리할 초안입니다.

## 저장 방식

- GitHub Pages: 화면 배포
- Supabase: 촬영 메모와 과정의 공동 저장
- Supabase Realtime: 변경 알림. 공개 알림에는 메모 내용이 들어가지 않습니다.
- 전용 링크의 무작위 키: 조회·수정 권한. 키는 공개 소스에 포함되지 않습니다.

전용 링크를 가진 사람은 촬영 목록을 편집할 수 있습니다. 일반 사이트 주소만 열면 개인 미리보기이며 공동 기록에는 접근하지 않습니다. 수술팀 기록을 저장할 때 GitHub 커밋은 발생하지 않습니다.

## 개발

```sh
npm ci --ignore-scripts
npm run build
```

`src/`를 수정한 뒤 빌드한 `highst-review.html`과 함께 커밋합니다. 프로젝트는 정적 파일만 배포합니다. 실제 데이터와 팀 접근 키를 저장소에 커밋하지 않습니다.

DB 구조는 `supabase/migrations/`에 있습니다. 설치 시 별도로 무작위 팀 키의 SHA-256 해시를 비공개 스키마에 설정하고 `supabase/filming-seed.json`으로 초기 목록을 넣습니다. 브라우저에는 공개 publishable key만 사용합니다.

로고와 사진의 권리는 원 권리자에게 있습니다. Pretendard 및 Supabase 클라이언트의 라이선스는 `assets/`에 포함했습니다.
